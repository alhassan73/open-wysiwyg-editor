Headless — bring your own UI

        
Same engine, no built-in interface. These four buttons are the page's own markup:

        

          
          
          
          
        

        

        
const editor = createEditor({ element, ui: false, ariaLabel: "Comment" });
boldButton.onclick = () => editor.chain().focus().toggleBold().run();
editor.subscribe(() => boldButton.setAttribute("aria-pressed", editor.isActive("bold")));

Install

        
npm install open-wysiwyg-editor     # or: pnpm add open-wysiwyg-editor

        
import { createEditor } from "open-wysiwyg-editor";
import "open-wysiwyg-editor/style.css";

const editor = createEditor({
  element: document.querySelector("#editor"), // a <div> or a <textarea> inside a form
  onUpdate: (e) => save(e.getHTML()),
});

        

          No bundler? Use dist/open-wysiwyg-editor.global.js from a CDN and call
          OpenWysiwygEditor.createEditor() — that is exactly what this page does.
